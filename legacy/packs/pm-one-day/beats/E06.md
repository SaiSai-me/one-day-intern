# E06 用户访谈：年轻创作者为什么拍了不发
- type: choice
- actors: [slacker]
- 监听: card.action.trigger(180s)
- timeout_fallback: 玩家未选择 → 阿摸发送三条用户原话摘要，摸鱼指数 +1，进 E07
- 降级: 卡片回调不可用 → 文字二选一

## 演出
阿摸私聊玩家，提供三条年轻创作者的用户原话：

- “vlog 都剪完了，封面总抽到我闭眼的那一帧，挑半天最后先存草稿了。”
- “标题、话题、地点一排都让我填，我只是想发个社团演出，不知道哪些真的有用。”
- “我想先发给朋友看，最怕手滑公开；发布前能不能让我再确认一次谁能看到？”

发卡片，让玩家选择优先深挖的流程问题：

| 按钮 | 效果 | 跳转 |
|---|---|---|
| 「封面与发布信息」 | 阿摸补充选封面、标题、话题和地点设置的放弃案例，并给出固定技术约束 | E07 |
| 「隐私与上传重试」 | 阿摸补充误公开、设置丢失和上传失败案例，并给出固定技术约束 | E07 |

## 判定
- 选择写 `branch_flags.E06(cover_metadata / privacy_retry)`；两条路都获得真实用户证据和技术约束。
- 玩家能用一句话说明原话如何改变其方案 → 好感度_boss +1，并把该判断写入 memory 供 E07 引用。
