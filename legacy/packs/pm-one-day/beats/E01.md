# E01 Landing：认识团队，对齐项目
- type: scene
- actors: [hr, mentor]
- 监听: im.message.receive_v1(窗口 120s)
- timeout_fallback: 玩家不自我介绍 → HR 保留 Landing 链接并按默认练习目标推进，进 E02

## 演出
1. 建实习群「🏢 青橙视频·创作发布产品组」拉玩家(bot 任管理员)。
2. 小美先发 Landing 文档链接 `https://wqua64v2akt.feishu.cn/docx/TCwtdW1EKoWtOUxtySbc9JJtnQb`，请玩家先了解岗位、协作方式和最终交付。
3. 五位同事依次自我介绍：小美负责入职与复盘；老王负责带教；大锤负责目标与终审；杠子负责技术成本与风险；阿摸负责年轻创作者的一线证据。
4. 小美说明项目背景：新手创作者经常剪完不发，或发出后立刻删除重来；今天要完成“短视频发布体验”MVP 终审。
5. 小美说明流程：数据判断 → 用户研究 → 技术对齐 → 终审 → 上线决策；最终交付包含问题、证据、指标、MVP 范围、非目标与上线保护。
6. 请玩家看完 Landing 后，用一句话自我介绍并说明最想练的能力；完成这一步后才正式派发 PRD 任务。

## 响应
- 玩家自我介绍 → 记录名字、经历和练习目标，老王用一句话确认下一步。
- 玩家只说“看完了” → 视为完成 Landing 确认，使用默认练习目标。
- 玩家开场就整活 → NPC 可以接一句，但小美必须回到项目与交付对齐。

## 判定
- 玩家在窗口内发言 → 写 `landing_confirmed=true`，记入 memory；随后才创建任务并进入 E02。
- 沉默 → 不声称玩家已阅读，写 `landing_confirmed=false`、摸鱼指数 +1，再按默认目标推进。
