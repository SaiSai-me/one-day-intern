# E02 晨会：看板读数

- type: calendar + sheet
- actors: [boss, mentor, backend]
- 监听: im.message.receive_v1（窗口 180s）
- timeout_fallback: 老王只提醒玩家回到看板完成问题卡，不在群聊复述 KPI

## 演出

1. 建日程「☀️ 创作发布产品组晨会（15min）」并邀请玩家。
2. 按 [数据看板规格](../data-dashboard.md) 创建并回读校验飞书电子表格；只有工作簿、口径、原生图表和 revision 全部确认后，才把状态标为 `ready`。
3. 老板 Chat 中，大锤只发一句：`【总监·大锤】先别急着改页面。看完数据后告诉我：最值得先解决的是哪个问题信号，为什么？`
4. 导师 Chat 中，老王只发看板链接和任务：`【导师·老王】数据都在这张看板里：<dashboard_url>。先看 KPI、口径和图表，再回我一张三格问题卡：谁受影响、卡在哪里、哪条数据支持。`
5. 不得在 Chat 中复述 41%、47% 或 18%，不得把看板内容拆成多条消息。

## 响应

- 玩家提出具体用户、环节或证据，并意识到指标分母不同 → 大锤追问一句“成功怎么算？”；玩家接住后，老王私下确认其判断。
- 玩家直接列功能 → 老王示范把功能改写成问题假设，再让玩家完成问题卡。

## 判定

- 玩家接住追问 → `boss_affinity +1`
- 沉默 → `slack +1`，只发送看板链接与问题卡起点。
- 看板创建或校验失败 → 留在 E02，修复看板；禁止退回群聊播报 KPI。
