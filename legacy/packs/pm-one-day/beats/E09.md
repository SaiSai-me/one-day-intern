# E09 上线决策：“仅朋友可见”变成了公开
- type: scene
- actors: [boss, mentor, slacker]
- 监听: im.message.receive_v1(窗口 120s,接住玩家的任何哀嚎)
- timeout_fallback: 直接进 E10

## 演出
1. 阿摸同步试点事故：一名用户上传失败后重试，原来选择的“仅朋友可见”被重置成“公开”，视频已经发出去了。
2. 杠子补充：20 名新手里有 15 人顺利发布，但 3 次断点重试没有保住原来的可见范围；可以由服务端保留设置，并在重试前再次确认。
3. 大锤要求玩家决定明早是否继续灰度。
4. 老王提示上线决定至少说明：范围、保护措施、观察指标、回滚条件。

## 响应
- 玩家选择小范围灰度，并加入设置保留、可见范围二次确认或快速撤回 → 好感度_boss +1
- 玩家选择暂停且给出修复、复测和重新灰度条件 → 不扣分
- 玩家选择直接全量且无保护 → 吵架次数 +1，结局记录因可见范围重置导致误公开而回滚

## 判定
- 把玩家的上线范围、保护措施、观察指标和回滚条件写入 memory，供日记引用。
