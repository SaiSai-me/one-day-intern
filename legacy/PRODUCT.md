# 一日实习生 · 产品概念说明文档

> **基于飞书 + 本地 AI Agent 的游戏化实习模拟器 · 开源平台**
>
> 在家抠脚，好想实习！怎么办 → 打开一日实习生，当场上班。

---

## 一、这是个什么产品？

**一日实习生**是一个开源的、游戏化的实习体验平台。用户下载一个「一日实习包」，接上自己本地的 AI Agent（如 Trae、Claude Code 等）和个人飞书账号，就可以在一个虚构的公司里沉浸式地上一天班——被派活、拉进群、开会吵架、评审被怼、摸鱼划水，下班还能自动生成一份可截图分享的搞笑「实习日记」。

它**不是**传统的视频游戏，也**不是**在线课程：
- 没有游戏客户端，玩家不需要下载 App
- 没有服务器跑游戏逻辑，推理完全在玩家本地 AI 上
- 飞书就是玩家唯一的"屏幕"——群聊、私聊、任务、日程、文档、会议就是游戏画面
- AI Agent 同时充当"导演"（控流程）和"全体演员"（即兴生成 NPC 对白）

**一句话定位：** 引擎是说明书，剧本是分幕的提示词弹药，Agent 是玩家自带的主机，飞书是画面，平台是发行方+直播间。

## 二、核心创意与价值

### 2.1 产品出发点

实习本应是探索不同工作体验的方式，但现实中实习门槛越来越高、垂直经验越来越被看重，这反而打破了实习的初衷——**为什么不可以随意到处实习呢？**

一日实习生的答案是：让每个人都能零成本、零风险地"体验一份工作一天"，体验完还能留下一份搞笑的实习日记。

### 2.2 对三类用户的价值

| 用户类型 | 痛点 | 产品价值 |
|---|---|---|
| **没进过大厂的新手**（迷雾小白） | 对大厂实习一头雾水，训练营太重太贵太严肃 | 零成本、零风险、轻松搞笑的职场预演习，满足好奇心，求职助跑 |
| **想分享工作的大厂打工人**（上班上美了） | 日常工作有素材但难沉淀、难分享 | 把自己的一天做成"实习包"，复盘+分享+夹带私货 |
| **职场内容创作者**（职场段子手） | 有一肚子段子，但从零写 AI 剧本门槛极高 | 创作工具把做"包"变简单，产出可复用可分发的 UGC 内容 |

### 2.3 独特优势

1. **零后端推理成本**：NPC 对白由玩家本地的 AI Agent 即兴生成，平台不烧 GPU
2. **零部署门槛**：不需要服务器跑游戏，不需要 API Key，打开 Agent 说"开始实习"即可
3. **天然即兴**：Agent 本身就是 LLM，NPC 对话无需额外 API 调用，自带上下文理解
4. **Agent 中立**：任何能跑 shell + 读写文件 + 遵循自然语言指令的 Agent 都能当引擎
5. **纯数据包安全**：实习包只有 Markdown + JSON，不含可执行代码，可审计
6. **节奏自由**：demo 默认 20 分钟速通，也能调成 60-90 分钟沉浸模式，一句话即可调速

## 三、目标用户画像 · SELECT PLAYER

### PLAYER 01 · 迷雾小白
- **身份**：没进过互联网大厂的新手村玩家，学生或转行求职者
- **痛点**：对"大厂实习到底怎么上班、群里怎么说话、会怎么开"完全没概念；正经课程太重太贵
- **使用场景**：在家好奇想试试→打开网站→下载实习包→在 Trae 里说"开始 demo"→20 分钟体验完

### PLAYER 02 · 上班上美了
- **身份**：在职大厂打工人，有实习/工作经验
- **痛点**：想让朋友也体验自己在上什么班，想复盘、想夹带私货
- **使用场景**：实习结束→在平台创建自己的实习包→分享给朋友/发小红书→朋友下载体验同款班

### PLAYER 03 · 职场段子手
- **身份**：职业内容创作者（自媒体、博主、职场 UP 主）
- **痛点**：有一肚子段子和岗位经验，但把它做成"AI 剧本"门槛高
- **使用场景**：用编排器产出高质量产品经理/运营/设计实习包→上传平台→涨粉恰饭

## 五、核心运行机制

### 5.1 一天怎么过？——主循环（常听模式）

引擎的心脏是一个"常听循环"：
1. **开局**：Agent 自检→获取玩家飞书 open_id→问玩家选模式（demo速通/沉浸）→初始化 state→执行第一幕 E01（HR 拉群欢迎）
2. **循环中**：
   - Agent 用 `lark-cli event consume` 竖着耳朵监听飞书消息（有超时）
   - 收到玩家消息 → 补读新消息 → NPC 即兴回应 → 更新状态和日志
   - 超时（到下一幕时间点）→ 自动触发下一幕：读 beats/下一幕.md → 执行幕动作（派活/开会/评审等）
3. **幕是背景的钟声，不是轮流说话的闸门**：玩家随时可以插话，引擎随时竖着耳朵听
4. **收尾**：最后一幕 wrap_up → 退出循环 → 基于日志自动生成实习日记 HTML

### 5.2 节奏系统（Timing）

| 预设 | 总时长 | 适用场景 |
|---|---|---|
| demo-fast（速通） | ~10 分钟 | 快速尝鲜 |
| demo（标准） | ~18-22 分钟 | 推荐首次体验 |
| demo-chill（慢） | ~28-35 分钟 | 边摸鱼边玩 |
| immersive（沉浸） | ~60-90 分钟 | 深度体验 |

运行中玩家说一句话就能调速：
- 「快进」/「加速」/「速通」→ 切到 demo-fast
- 「慢一点」→ 间隔×1.5
- 「暂停」/「停一下」→ 暂停
- 「继续」→ 恢复
- 「X分钟速通」→ 动态重算节奏
- 「跳过」/「next」→ 立即进下一幕

### 5.3 三栏契约（产品边界）

| 类别 | 谁决定 | 例子 |
|---|---|---|
| **写死的** | 实习包作者 | 公司名字、有哪几个 NPC、一天有几幕、关键事件（如评审会必须发生） |
| **AI 即兴的** | 本地 Agent | NPC 的具体对白、表情、回应内容、突发摸鱼事件 |
| **玩家输入** | 玩家 | 说什么话、做什么选择、选反抗还是顺从、摸不摸鱼 |

### 5.4 双通道感知（防漏消息）

飞书 WebSocket 事件是"门铃"（1-2 秒到达），但 AI 思考期间可能漏消息。所以：门铃响后，Agent 先用消息列表 API 从游标补读全部新消息，再统一回应。

### 5.5 世界状态 state.json

```json
{
  "pack_id": "pm-one-day",
  "mode": "demo",
  "current_beat": "E05",
  "gauges": { "好感度_boss": 1, "摸鱼指数": 2, "吵架次数": 1 },
  "memory": ["E03 玩家选了反抗线"],
  "branch_flags": { "E03": "rebel" },
  "timing": { "preset": "demo", "paused": false }
}
```
每次状态变化原子写盘，终端崩了说「继续上班」就能无损续跑。

### 5.6 行为日志 log.jsonl

逐行 JSON 追加，是判定结果和实习日记的**唯一事实来源**，日记生成绝不虚构：
```json
{"t":"14:05","beat":"E01","kind":"message","who":"hr","text":"欢迎新同学！"}
{"t":"14:20","beat":"E03","kind":"choice","who":"player","text":"rebel","data":{"option":"当场反驳"}}
```

## 六、网站功能详解

平台网站（web/）基于 **Next.js 16 + React 19 + Tailwind CSS 4 + Supabase** 构建，采用像素风 UI 设计。

### 6.1 页面地图


### 6.2 首页 `/`

首页是产品的第一印象，采用像素风视觉：

- **顶部导航栏**：logo、实习集市、我的实习、实习看板、使用指南、+ 创建实习包
- **HERO 头图区**（来自产品概念设计）：
  - 蓝色渐变天空 + 三朵像素云漂浮动画
  - 黄色浮动徽章「★ 开源 · 游戏化 · 实习模拟器 ★」
  - 大标题「一日实习生」带双层蓝色像素阴影
  - 打字机对话框（闪烁光标，循环播放实习生酱的台词）
  - **可互动的像素小人**（点击会跳跃并随机弹出大厂黑话台词气泡）
  - 三个像素按钮：「▶ START 开始实习」（平滑滚动到内容区）、「📖 怎么玩？使用指南」、「🛠 我要造班」
  - 底部闪烁提示「- PRESS START TO BEGIN -」
- **大厂黑话跑马灯**：无限循环的"对齐 ▸ 抓手 ▸ 闭环 ▸ 颗粒度 ▸ 拉通 ▸ 赋能..."
- **四大板块入口**：实习集市、我的实习、实习看板、创建实习包
- **三步上岗**：①领实习包 → ②喊 AI 开机 → ③去飞书上班
- **产品概念讲解区**（点击"开始实习"或滚动可见）：
  - **STAGE 1 · 创意介绍**：双栏卡片（这是什么游戏 / 产品出发点）+ 公式行（Agent+飞书+平台=模拟器）+ **「你的一天」任务链**（7 个可点击打卡的像素任务图标：被AI派活→建立日程→被拉进群→开会吵架→评审被怼→摸鱼划水→生成实习日记，全打卡弹Toast通关庆祝）
  - **STAGE 2 · 目标用户**：三位玩家卡片（迷雾小白/上班上美了/职场段子手），每张带像素头像、痛点描述、经典语录、debuff/buff 标签，可点击选中
  - **STAGE 3 · 价值与意义**：用户价值（零成本职场演习）+ 创作者价值（全新UGC品类）+ **内容飞轮**（创作者→玩家→再创作↺ 积木复用·越滚越大）
  - **FINAL 总结横幅**：一句话总结产品使命
  - **READY PLAYER ONE CTA**：引导去使用指南或实习集市
- **滚动出场动画**：各区块进入视口时以像素步阶效果淡入
- **Toast 通知**：打卡/选角色/通关时右下角弹出像素风提示

### 6.3 实习集市 `/market`

按部门/分类浏览全网实习包的市场页。每个实习包以像素卡片形式展示，展示包名、岗位标签、作者、评分/游玩人数。支持按岗位（产品/运营/技术/设计等）筛选，点击进入包详情页。

### 6.4 使用指南 `/guide`

**5 步上手教程**，从零基础到开始游戏：
1. **安装 Trae IDE** — 下载并安装字节跳动 AI IDE
2. **在 Trae 终端安装飞书 CLI** — `npm` 安装 lark-cli
3. **配置飞书应用与登录** — 创建自建应用、OAuth 扫码授权
4. **准备实习包** — 下载实习包或用内置示例包
5. **开始实习！** — 在 Trae 中说"开始实习"选择模式启动

含常见问题 FAQ、调速指令速查、故障处置。

### 6.5 实习包详情页 `/packs/[id]`

展示单个实习包的详情：
- 包名、作者、岗位、时长、难度标签
- 公司世界观简介
- NPC 角色预览
- 一天幕表预览（E01 入职欢迎 → E10 生成日记）
- 下载按钮（下载 zip）
- 收藏按钮（加入"我的实习"）
- "怎么玩"简明指引

### 6.6 我的实习 `/my`

玩家个人收藏夹（基于 localStorage 存储）：
- 已收藏的实习包列表（像素工牌卡片样式）
- 快速开始按钮
- 本地游玩历史记录（后续可同步到云端）

### 6.7 创建实习包 `/create`

面向创作者（PLAYER 02/03）的 4 步教学页：
1. **① 想清楚你要复刻哪一天班** — 选岗位、选公司文化、定一天的关键节点
2. **② 让 Trae 的 AI 替你写（推荐）** — 用自然语言描述，AI 生成初始包
3. **③ 本地试跑一遍** — 在 Trae 里 demo 模式跑一次，调问题
4. **④ 打包上架** — 用编排器精修，导出 zip，上传平台
- 提供可视化编排器入口和包格式规范链接

### 6.8 上传实习包 `/upload`

创作者上传自己做好的实习包 zip：
- 填写包名、简介、标签、封面
- 上传 zip 文件
- 提交审核后上架实习集市

### 6.9 实习看板 `/dashboard`

**观战直播面板**（opt-in 功能）：
- 正在进行的实况列表（玩家 opt-in 上报状态）
- 每个实况显示：包名、当前幕、玩家昵称、关键量表（好感度/摸鱼指数等）
- 点击进入 `/runs/<id>` 实时观战页，看别人的上班进度和名场面
- 局终凝固为日记回放页，可作为社交分发物

### 6.10 编排器 `/editor`

独立的可视化实习包编辑器（来自项目根目录 `lark-workflow-editor.html`）：
- 文件管理面板
- 公司信息、NPC 人设、幕表的可视化编辑
- 时间线拖拽编排
- 一键导出为 zip 实习包

## 七、用户使用说明

### 7.1 玩家快速上手（5 步）

**第 1 步 · 前置准备**
- 安装 [Trae IDE](https://trae.ai)（字节跳动 AI IDE）
- 注册一个飞书账号（个人号即可）

**第 2 步 · 安装飞书 CLI**
打开 Trae 的终端，执行：
```bash
npx @larksuite/cli@latest install
```

**第 3 步 · 配置飞书应用与登录**
```bash
# 首次配置（会引导你创建一个飞书自建应用）
lark-cli config init --new

# 用户身份扫码登录
lark-cli auth login --recommend

# 验证状态（显示 OK 即可）
lark-cli auth status
```

**第 4 步 · 获取实习包**
- 方式 A：访问平台网站 → 实习集市 → 挑选一个岗位（推荐从官方「产品经理·一日实习」开始）→ 下载 zip → 解压到项目目录
- 方式 B：直接使用内置示例包 `packs/pm-one-day/`

**第 5 步 · 开始实习！**
在 Trae 里打开项目，直接对 AI 说：
- **「开始 demo」** → 标准 20 分钟快速体验（推荐首次）
- **「开始实习」** → 选择模式和实习包开始
- **「继续上班」** → 从上次中断的地方无损续跑

然后打开你的飞书——你会被 HR 拉进新人群，Leader 给你派任务，同事拉你摸鱼，老板在评审会上怼你的方案...祝你上班愉快！

### 7.2 玩家运行中指令

在飞书群里或 Trae 终端里随时可以说：

| 指令 | 效果 |
|---|---|
| 快进 / 加速 / 速通 | 切到 demo-fast 模式，节奏加快 |
| 慢一点 / 慢点 | 间隔时间 ×1.5 |
| 暂停 / 停一下 | 暂停剧情推进 |
| 继续 / go on | 从暂停恢复 |
| X分钟速通（如"10分钟速通"） | 动态重算节奏，在 X 分钟内通关 |
| 跳过 / next | 立即进入下一幕 |
| 继续上班 | 崩溃/中断后续跑 |

### 7.3 创作者快速上手（4 步创作）

**第 1 步 · 想清楚你要复刻哪一天班**
- 选岗位：产品经理？运营？设计师？后端？HR？
- 定公司文化：狼性大厂？佛系外企？创业公司？事业单位？
- 列关键节点：入职欢迎→派活→拉群对齐→中午摸鱼→下午开会→评审被怼→加班？准时下班？

**第 2 步 · 让 Trae 的 AI 替你写初版**
在 Trae 里说："帮我创建一个【XX岗位·一日实习】的实习包，公司文化是XXX，关键节点有XXX"——AI 会基于包格式规范帮你生成初始的 pack.json、company.md、personas/ 和 beats/。

**第 3 步 · 本地试跑一遍**
切到 demo 模式跑一次，检查：NPC 人设是否对味？节奏会不会太快/太慢？评审环节够不够刺激？根据试跑体验微调。

**第 4 步 · 打包上架**
- 打开编排器（浏览器访问 `/editor` 或直接打开 `lark-workflow-editor.html`）精修细节
- 点击「💾 导出」生成 zip
- 在平台网站 → 上传实习包 → 填写信息提交
- 分享给朋友来上你的班！

### 7.4 实习包格式简述

一个实习包是一个纯数据目录（无代码），结构如下：
```
<包名>/
├── pack.json         # 元信息：岗位、时长、难度、作者、所需飞书权限
├── company.md        # 公司世界观：名字、行业、文化、组织架构
├── timeline.md       # 一天骨架：幕列表（E01~E10）、标题、每幕核心事件
├── personas/         # NPC 人设卡：HR、导师、老板、同事、摸鱼搭子...
│   ├── hr.md         # 每张卡：职位、姓名、性格、口头禅、红线、说话风格
│   ├── mentor.md
│   └── ...
├── beats/            # 分幕演出指令（到幕才加载，防剧透）
│   ├── E01.md        # 每幕：开场动作、要发的消息/卡片/任务、触发条件、推进条件
│   ├── E02.md
│   └── ...
├── tasks/            # （可选）任务素材：PRD模板、评审要点、弹药库
└── diary/            # （可选）自定义日记模板
```
详细规范见 [docs/pack-spec.md](docs/pack-spec.md)。

## 八、一天任务链示例（产品经理一日实习）

以官方示例包 `pm-one-day` 为例，玩家体验的一天大致是：

| 幕 | 任务名 | 发生什么 |
|---|---|---|
| E01 | 被 AI 派活 | HR 拉你进新人群，发欢迎词，导师私聊布置第一个 PRD 任务 |
| E02 | 建立日程 | 导师在飞书日历给你建了"PRD 初稿截止"日程，群里艾特你 |
| E03 | 被拉进群 | 被拉进"XX项目对齐群"，7 条未读，前辈教你"先潜水不要说话" |
| E04a/E04b | 开会吵架 | 需求评审会，研发和产品对线，你可以选择顺从/当场反驳（分支） |
| E05 | 写 PRD | 被关小黑屋写文档，摸鱼搭子私聊喊你划水 |
| E06-08 | 各种突发 | 老板临时加需求、跨部门甩锅、下午茶摸鱼、方案被打回 |
| E09 | 评审被怼 | 最终评审会上老板对你的 PRD 提出灵魂拷问 |
| E10 | 生成实习日记 | 下班！Agent 根据日志生成搞笑实习日记，含名场面金句、好感度/摸鱼指数、评级 |

下班日记示例金句：
> "今天你一共被@了 23 次，开会 3 场，写文档 200 字，摸鱼 47 分钟。"
> "你在评审会上选择了当场反驳，荣获'血气方刚'成就，老板好感度-2，摸鱼搭子好感度+3。"
> "最终评级：B+（明天还来吗？）"

## 九、内容飞轮与生态

```
             ┌─────────────┐
             │   创作者     │  打工人/段子手制作实习包
             │  (PLAYER 2/3)│
             └──────┬──────┘
                    │ 上传分享
                    ▼
             ┌─────────────┐
             │  实习集市    │  平台分发、评分、推荐
             └──────┬──────┘
                    │ 下载体验
                    ▼
             ┌─────────────┐
             │    玩家      │  新手体验、玩出分支、出金句
             │  (PLAYER 1)  │
             └──────┬──────┘
                    │ 分享日记+想做自己的包
                    ▼
             ┌─────────────┐
             │   再创作     │  玩家变创作者，复用素材积木
             └──────┬──────┘
                    │
                    └────→ 循环往复，内容越滚越大 ↺
```

**积木复用机制**：人设、事件、任务都可以作为独立素材跨包复用。比如"狼性老板"人设卡、"评审会吵架"事件卡可以被多个实习包引用，降低创作门槛。

**未来扩展**：
- 企业招聘入驻：官方发布真实岗位的体验包，作为招聘前置筛选
- IP 联动：动漫/影视/游戏主题实习包（"在霍格沃茨当一天魔法部实习生"）
- 多人联机：2-4 个玩家同时入职，各自扮演不同角色互相对戏
- 日记社交：日记自动生成精美海报图，一键分享小红书/朋友圈

## 十、技术栈与项目结构

### 10.1 整体技术栈

| 层 | 技术 |
|---|---|
| 平台网站 | Next.js 16 (App Router) + React 19 + TypeScript + Tailwind CSS 4 |
| 数据库/后端 | Supabase（PostgreSQL + Auth + Storage + RPC） |
| 本地引擎 | Markdown 规范文档（ENGINE.md）+ AI Agent 自然语言理解 |
| Agent 适配器 | Trae Skill（.trae/skills/）、Claude Code Skill（.claude/skills/） |
| 飞书操作 | lark-cli（飞书官方命令行工具） |
| 编排器 | 零依赖单文件 HTML（lark-workflow-editor.html） |
| 像素风 UI | 纯 CSS（CSS 变量 + 像素边框 + steps 动画 + SVG 内联） |
