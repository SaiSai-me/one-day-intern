- Agent 中立引擎、通用剧情包与包规范
- 多页面平台、Supabase、市场、上传、直播看板等历史方案文档
- 旧版网页、海报和宣传素材
- v0.3、MVP、分享包和 Player 包等旧发布物
- 历史运行记录
