# E01 · 入职：领取终极任务

## 目标

建立四个有实际职责的工作群，并把本局唯一飞书任务指派给玩家。玩家从第一分钟起知道自己最终要完成的是一场产品评审，而不是陪 NPC 闲聊。

## 主工作群

`🏢 跳动大厂·入职台·<run_id后六位>`（`lobby`）。其他三个群分别是 `🧭 导师工作台`（`mentor`）、`🔎 用户研究台`（`research`）、`⚔️ 产品终审室`（`review`）。

## 工具动作

1. 按 CLI 契约先创建 lobby，并立即发送第一条 HR 消息作为 bot 建群/发消息能力探针；成功后再依次创建其余三个私有群，均加入玩家。每个群使用独立 UUID 和动作键 `E01.chat.create.<room_key>`。验证每个 `chat_id` 以 `oc_` 开头后写入 `state.chat_ids`。绝不把四个群压成一个，也绝不创建第五个群。
2. 创建并指派唯一任务 `完成「同城遛宠 MVP 终审」`，截止时间取当前时间后 45 分钟，动作键 `E01.task.create`。任务描述必须列出五项验收：问题、证据、指标、范围/非目标、上线保护。写入 `artifacts.task_id` 和任务 URL（若返回）。
3. 发送消息包：
   - 入职台 / HR：`【HR·小美】欢迎加入新体验组。你今天只接一件任务：完成「同城遛宠 MVP 终审」。四个工作群分别放了资料、辅导、研究和终审现场。`
   - 入职台 / HR：`【HR·小美】任务已指派给你：不是填空题，最终要由你在终审室讲清楚“为什么做、做什么、不做什么、怎么安全上线”。`
   - 导师工作台 / 老王：`【导师·老王】我会陪你把这件事拆小：先做问题卡，再做证据卡，再写终审陈述。每次我只帮你改一处，决定还是你来下。`
   - 用户研究台 / 阿摸：`【运营·阿摸】我负责给证据，不负责替你拍板。等你来拿用户原话。`
   - 产品终审室 / 大锤：`【总监·大锤】45 分钟后见。终审不要功能清单；我要一套能被研发执行、能被用户验证的判断。`

## 等待输入

在入职台等待玩家群聊文字 90 秒。接受数字或任何自定义目标：想重点练判断、沟通、评审表达，或只想体验一次终审。

## 判定

- 保存玩家原文到日志，把目标摘要写入 `flags.player_goal`；后续导师反馈和日记必须呼应它。
- 玩家顺便自我介绍时，记录名字、经历或善意花名到 `memory`。
- 老王在导师工作台用一句话确认下一步：`【导师·老王】目标收到。来工作台做第一张问题卡，别急着画功能。`

## 沉默兜底

写 `flags.player_goal="完成一次能说清理由的终审"`；老王在导师工作台发送 `【导师·老王】我先按“把判断说清楚”带你走。第一站：问题卡。`，`slack +1`。
